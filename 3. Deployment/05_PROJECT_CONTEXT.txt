# PROJECT CONTEXT - AI Interview Platform

## PROJECT NAME
AI-Assisted Applicant Screening and Ranking System

## PROJECT TYPE
MCA Final Year Project

## TECHNOLOGY STACK

### Backend
- **Language**: Python
- **Framework**: Flask
- **Database**: SQLAlchemy ORM
- **Database Engine**: MySQL/SQLite (SQLite for development, MySQL for production)

### Frontend
- **HTML**: HTML5
- **CSS**: CSS3 with Bootstrap 4
- **JavaScript**: Vanilla JavaScript with jQuery
- **UI Framework**: Bootstrap 4.5.2
- **Icons**: Font Awesome 6.4.0

### AI/ML
- **AI Model**: Google Generative AI (Gemini)
- **Speech-to-Text**: Whisper (faster-whisper)
- **NLP**: spaCy, NLTK
- **Resume Parsing**: Custom parser with PDF/DOCX support
- **Libraries**: pdfminer.six, docx2txt

### Data Visualization
- **Library**: Chart.js (planned for analytics dashboard)

## CORE FEATURES

### 1. Authentication
- User registration and login
- Role-based access control (Admin, Recruiter, Candidate)
- Session management
- Password hashing

### 2. Resume Upload
- File upload support (PDF, DOCX, TXT)
- File validation and security
- Secure filename handling
- File size limits

### 3. Resume Parsing
- PDF parsing using pdfminer.six
- DOCX parsing using docx2txt
- Text extraction and processing
- Structured data extraction:
  - Name
  - Email
  - Mobile number
  - Skills
  - Experience
  - Education
  - College name

### 4. Skill Extraction
- Regex-based skill extraction
- Skill matching from predefined lists
- Skill categorization
- Skill confidence scoring

### 5. Job Management
- Create job postings
- Edit job details
- Delete job postings
- Job-specific skill requirements
- Job-specific question templates

### 6. Dynamic Weightage
- Configurable weightage per skill
- Position-specific weightage
- Customizable evaluation criteria
- Weight adjustment based on job requirements

### 7. Weighted Scoring
- AI-powered answer evaluation
- Technical accuracy scoring (1-10)
- Communication scoring (1-10)
- Problem solving scoring (1-10)
- Weighted final score calculation
- Qualitative feedback generation

### 8. Candidate Ranking
- Rank candidates by weighted scores
- Filter by skills/experience
- Compare candidates side-by-side
- Generate ranking reports
- Export ranking data

### 9. Recruiter Dashboard
- Candidate overview table
- Average scores display
- Status tracking (Active/Completed)
- Detailed candidate profiles
- Turn-by-turn Q&A review
- Performance metrics

### 10. Real-Time Features
- Streaming AI responses (zero lag)
- Voice input with Whisper STT
- Grammar checking
- Speaking pace analysis
- Real-time feedback
